# برنامج تحليل الفجوة

صفحة ويب واحدة (index.html) لتقييم ملاحظات تحليل الفجوة:
- تحديد كل ملاحظة: مستوفي / غير مستوفي
- إضافة ملاحظات جديدة
- حساب النسبة المئوية لكل خانة من إجمالي الملاحظات وعرض النتيجة

## التشغيل
افتح ملف index.html في أي متصفح، أو فعّل GitHub Pages من:
Settings ← Pages ← Branch: main ← Save
